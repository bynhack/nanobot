# Case Audit Feature Tracker

目标：用长期维护的功能台账记录“涉诈资金审计”独立功能已经完成什么、部分完成什么、还缺什么。

## 状态说明

- `Done`: 当前产品路径可用，并已进入本地发布或有基本验证。
- `Partial`: 主链路存在，但仍缺产品闭环、体验一致性或更完整验证。
- `Missing`: 目前没有可用产品入口或后端链路。
- `Deferred`: 明确暂不实现，或已选择替代方案。

## 维护规则

- 功能状态变化时，优先更新本文。
- 如果状态变化会改变待修复问题或产品决策，同步更新 `pending-fixes.md`。
- 不把临时计划、日期化发布笔记写进本文；这里保存长期有效的能力状态。
