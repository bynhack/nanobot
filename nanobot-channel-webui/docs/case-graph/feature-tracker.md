# Case Graph Feature Tracker

目标：用一张长期维护的功能台账记录当前上图产品已经完成什么、部分完成什么、还缺什么。本文只记录当前 `nanobot-channel-webui` 的产品状态，不再按原版实现做差异跟踪。

## 状态说明

- `Done`: 当前产品路径可用，并已有基本验证或已进入本地发布流程。
- `Partial`: 主链路存在，但仍缺产品闭环、入口、边界能力或更完整验证。
- `Missing`: 目前没有可用产品入口或后端链路。
- `Deferred`: 明确暂不按某种候选方案实现，或已选择替代实现。

## 维护规则

- 功能状态变化时，优先更新本文。
- 如果状态变化会改变待修复问题或产品决策，同步更新 `pending-fixes.md`。
- 不把临时计划、日期化发布笔记写进本文；这里保存长期有效的能力状态。
- 每个 `Done` 项尽量保留代码证据、测试证据或本地发布证据，避免只凭记忆标记完成。
