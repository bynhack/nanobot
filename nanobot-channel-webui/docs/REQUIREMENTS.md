# 需求清单

本文件用于跟踪产品能力、架构目标和明确需求。它和 `docs/FIXME.md` 分工不同：需求清单描述“要建设什么”，修复清单描述“当前哪里不符合预期或存在风险”。

## 状态约定

- `待设计`：方向明确，但方案未定。
- `待实现`：方案明确，可以进入开发。
- `进行中`：正在实现。
- `已完成`：已经实现、发布并完成必要验证。
- `延后`：暂不做，需要说明原因。
- `取消`：确认不再需要。
