# Case Graph Incremental Layout Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace scattered case-graph layout patches with one clean incremental layout engine that preserves existing/manual positions, grows new nodes from semantic anchors, and handles groups as layout entities.

**Architecture:** Add a focused frontend `layout-engine` module. Initial graph layout uses G6's same layout package for global placement, while later relation/group/manual operations use semantic incremental layout events and persist layout-engine output. GraphCanvas renders positions and emits manual drag events only. Backend state stores versioned `layout.nodePositions`, `layout.positionMeta`, and `layout.groupLayout` without calculating positions.

**Tech Stack:** React 19, TypeScript, Vitest, AntV G6 rendering, Python backend state storage.
