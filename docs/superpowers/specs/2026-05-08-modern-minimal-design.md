# Nanobot WebUI 视觉重构设计方案 - 现代极简 (Modern Minimal)

> **日期**: 2026-05-08
> **目标**: 将 nanobot-channel-webui 现有样式重构为现代、精致、高生产力的“现代极简”风格。
> **参考风格**: Linear, Vercel, Apple.

## 1. 核心设计原则

- **高对比度与呼吸感**: 增加组件间的间距，使用清晰的层级关系，减少视觉杂讯。
- **精致的阴影与边框**: 放弃生硬的阴影，改用多层叠加的柔和阴影 (Soft Shadows)；边框采用极其淡雅的灰色。
- **动态响应**: 确保在不同设备和 Light/Dark 模式下都具备极佳的阅读体验。
- **交互反馈**: 每一个动作（点击、悬浮、拖拽）都应有丝滑的微动效。

## 2. 视觉规范 (Theme Configuration)

我们将利用 Tailwind CSS 4 的变量体系，在 `styles.css` 中定义核心设计语言：

### 🎨 色彩体系 (Colors)
- **Primary**: 使用深邃的墨黑色 (`#000000`) 或深灰色 (`#171717`) 作为文字和核心按钮的主色。
- **Accent**: 精致的蓝色 (`#007AFF`) 用于链接和重要状态。
- **Background**: 
  - Light: 纯白背景 (`#FFFFFF`) 配合极淡灰色的容器 (`#FBFBFB`)。
  - Dark: 深邃黑背景 (`#0A0A0A`) 配合带透明度的卡片。

### 📐 形状与间距 (Shapes & Spacing)
- **圆角 (Radius)**: 
  - 容器/卡片: `1.5rem` (24px)。
  - 消息气泡: `1rem` (16px)，并采用连续圆角逻辑。
- **投影 (Shadows)**:
  - `shadow-sm`: `0 1px 2px rgba(0,0,0,0.05)`
  - `shadow-md`: `0 8px 30px rgba(0,0,0,0.04)`

## 3. 核心组件重构方案

### 💬 消息流 (Message Thread)
- **消息气泡**:
  - 用户消息: 深色背景，白色文字，带微弱的蓝色偏向阴影。
  - 助手消息: 纯白/深灰背景，淡灰色边框，去除背景色块，强调内容本身。
- **头像**: 极简图标或纯色圆形占位，尺寸缩小至 `32px`。
- **间距**: 消息组之间增加 `2rem` 的间距，提升阅读专注度。

### ⌨️ 输入框 (Composer)
- **结构**: 悬浮式卡片设计，带有明显的毛玻璃背景模糊效果。
- **文件预览**: 采用横向滚动的精致小卡片样式，增加删除按钮的悬浮显示。
- **状态提示**: 技能选择器 (Slash Command) 采用弹出式弹出框，带有平滑的垂直位移动画。

### 📄 Markdown 渲染
- **字体**: 正文使用 `Inter`，代码块使用 `JetBrains Mono`。
- **代码块**: 采用深色模式风格（即使在浅色主题下），增加一键复制按钮。
- **表格**: 极简线条，去除斑马纹，增加悬浮高亮。

## 4. 动效与交互 (Animations)

- **进入动画**: 消息加入时采用 `Spring` 物理引擎驱动的淡入并轻微上移。
- **状态切换**: Light/Dark 模式切换增加圆圈扩散式的遮罩动画。
- **加载状态**: 思考时不再使用闪烁，而是采用精致的线条流动动画。

## 5. 技术实现计划

1.  **全局基础**: 更新 `styles.css`，定义新的 CSS 变量和 Tailwind Base 类。
2.  **Layout 重构**: 调整侧边栏和主聊天区域的布局比例与阴影。
3.  **组件迭代**: 依次重构消息组件、输入框组件和 Markdown 渲染器。
4.  **细节打磨**: 添加动画效果，测试移动端兼容性。
